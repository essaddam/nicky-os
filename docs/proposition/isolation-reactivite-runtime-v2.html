3. Workflows : tous les types

3.1 Ce que le moteur sait faire aujourd'hui

Un automatisme est un graphe à la manière de n8n (moli-automation/src/model.rs) :

  • Déclencheurs : changement d'état, seuil (avec durée « depuis »), occurrence (appui), heure, soleil, période, démarrage, manuel.
  • Logique : If avec des règles ET/OU sur un état, l'heure ou le soleil ; l'imbrication passe par des If en chaîne.
  • Actions : Set, Toggle, Scene, Wait, WaitFor, Notify, Write (texte rédigé par l'assistant).
  • Modes d'exécution : restart, single, queued.

Plafonds actuels : 400 automatismes (lib.rs:994), 60 nœuds et 120 liens par graphe (check.rs:16-17), 100 étapes par exécution (run.rs:17), ni boucle, ni variable, ni calcul, ni lecture d'historique. Garde-fou anti-emballement : au-delà de 20 lancements par minute, l'automatisme est éteint (engine.rs:15-16). Un automatisme branché sur un capteur bavard (puissance, mouvement) est donc coupé, pas ralenti.

À côté du moteur, le hub porte déjà des primitives durables : minuteurs, compteurs, plannings, calculs (agrégats min/max/moyenne), scènes et, depuis 5bf57b1, durées avec couverture connue (moli-runtime/src/durations.rs, échantillonnées sous le verrou du modèle avec un index par point et un écrivain durable à part). C'est le bon germe pour les agrégats en mémoire.

3.2 Le vrai moteur sous charge

Chaque automatisme du banc a 1 déclencheur, 3 conditions imbriquées de 3 règles et 1 action ; 10 % sont temporaires (« allume 30 min »), 10 % attendent une condition (wait_for) ; 1 800 capteurs et 400 lampes, la forme d'une grosse maison.

Lecture :

  • En croisière, le moteur est très réactif.
  • Dans une rafale (un pont qui se reconnecte et republie tout), chaque événement coûte au moteur environ 60 ns par automatisme, qu'il le concerne ou non : il les parcourt tous (engine.rs:351-357). À 400 automatismes, ~30 µs par événement ; estimé 0,3 à 0,6 ms sur un Pi Zero 2 W, soit un retard du bus dès qu'une rafale dépasse ~1 000 événements.
  • Créer et valider les automatismes un par un coûte de plus en plus cher : 0,3 s pour 50, 17,5 s pour 400 (environ 60 ms par enregistrement quand 300 existent).

3.3 Un retard du bus perd des déclencheurs, même après la rafale Élevé

À 5 000 événements, le moteur prend du retard sur le bus (Lagged) et les cinq déclencheurs injectés juste après la rafale ne partent jamais. Le mécanisme est dans le code :

  1. Sur Lagged, le moteur appelle remember_all() (engine.rs:77-85), qui recopie les valeurs actuelles du hub dans sa table last (engine.rs:340-349).
  2. Ces valeurs contiennent déjà les événements encore en file.
  3. Quand le moteur lit ensuite ces événements, on_state voit valeur précédente == nouvelle valeur et s'arrête (engine.rs:351-356).

Un retard ne perd donc pas seulement les événements sautés ; il neutralise aussi ceux qui restent. Correctif simple : sur Lagged, comparer l'instantané à last et produire une transition pour chaque valeur qui a changé, au lieu d'écraser last.

3.4 Workflows temporaires Élevé

« Allume pendant 5 minutes » devient set on → wait 300 → set off (moli-assistant/src/before.rs:86). L'attente est une tâche en mémoire ; à l'arrêt, les exécutions en cours sont interrompues (engine.rs:99-113) et rien ne les reprend au démarrage. Après un redémarrage, une mise à jour ou une bascule, la lumière reste allumée.

Proposition : un bail durable, primitive à part entière.

  • allumer le salon pour 30 minutes = un ordre et une échéance absolue, persistés ensemble (une écriture synchronisée, 3,4 à 3,7 ms mesurées, une seule fois au lancement).
  • Le retour est conditionnel : il n'éteint que si la valeur est toujours celle que le bail a posée ; si quelqu'un a changé la lumière entre-temps, le bail s'éteint sans rien faire.
  • Un nouveau « 30 minutes » prolonge le bail au lieu d'en empiler un second.
  • Au redémarrage ou sur la machine de secours, un bail échu s'applique une fois, un bail en cours reprend son attente, comme les minuteurs AUTO-H1 le font déjà pour leur état.
  • C'est un ordre de la famille, jugé par la garde et journalisé comme les autres ; ce n'est pas un automatisme permanent, il n'a pas besoin d'une validation par PIN.

10 000 baux en attente coûtent 0,3 à 0,4 ms d'ordonnancement au total (tas binaire, I4).

3.6 Le moteur cible

validation humaine ──► compilation ──► plan exécutable
                         │   points numérotés, constantes typées, expressions compilées,
                         │   bornes vérifiées (nœuds, profondeur, boucles, sous-workflows)
                         ▼
hub ──(événements des points indexés seulement)──► file du moteur ──► index par point
                                                                   ├─► agrégats au fil de l'eau
horloge : prochaine échéance (tas), pas de balayage à 1 Hz ────────┤
                                                                   ▼
                                     exécutions : machines à états ; curseur et baux
                                     persistés aux points d'attente (wait, wait_for, bail)
  1. Compiler à la validation. La validation humaine porte déjà sur une empreinte exacte ; la compilation produit au même moment un plan exécutable, sans relire le JSON ensuite.
  2. Filtrer à la source. Le hub ne transmet au moteur que les événements des points indexés (déclencheurs, conditions en attente). Une rafale de capteurs qu'aucun workflow ne regarde n'entre plus dans sa file.
  3. Index et horloge par échéance. Un événement ne réveille que ses déclencheurs ; l'heure ne réveille le moteur qu'à la prochaine échéance due (aujourd'hui : chaque seconde, avec un recalcul du soleil par déclencheur, engine.rs:499-536).
  4. Exécution durable. Une exécution est une machine à états ; son curseur et ses baux sont persistés aux points d'attente. Un redémarrage ou une bascule la reprend.
  5. Workflows façon n8n. Sous-workflows appelés par identifiant (profondeur bornée), boucles sur des listes bornées, variables typées, branches d'erreur et de délai. Toujours déterministe, toujours sous la garde, jamais de LLM dans l'exécution.
  6. Garde-fou d'emballement. Remplacer l'extinction au-delà de 20 lancements par minute par un anti-rebond et une coalescence par déclencheur ; l'extinction reste le dernier recours, annoncé.

Option Effet Coût Choix
A. Garder le moteur, corriger la perte sur retard, indexer les déclencheurs d'état, rendre wait durable Supprime les deux défauts graves Faible à moyen d'abord

4. Tampons et cloisons

4.1 Ce qu'un tampon résout, et ce qu'il ne résout pas

  • Un tampon (une file) absorbe une différence de vitesse : un appareil lent, une rafale. Il doit être borné, avoir une règle quand il est plein (refuser, coalescer, remplacer) et une échéance (un ordre trop vieux ne part pas).
  • Un tampon ne libère pas un thread occupé : si un pilote bloque son worker, la file derrière lui n'avance plus. Contre cela, il faut une cloison : un thread à part.
  • La V1 a montré que deux pilotes bloquants gèlent la maison (E2). Les mesures ci-dessous disent quelle cloison ou quelle file résout quel cas.

4.2 « Tout passe par le moteur » : vérification

C'est exact. Chaque valeur passe par ctx.set_state (verrou du modèle puis bus), chaque ordre par hub.command (garde, échéance, journal), et le moteur d'automatismes est un abonné du bus. Mettre un pilote sur son propre thread ne coupe rien : le hub est une mémoire partagée et ses canaux Tokio fonctionnent d'un runtime à l'autre.

Preuve (K1) : capteur → vrai moteur → lampe. Le capteur et la lampe tournent sur leurs propres threads, deux pilotes bloquants aussi, et le moteur reste sur le runtime du cœur.

Configuration Médiane Pire
Pilotes partagés sur les 2 workers 5,5 à 12,1 ms 202 à 204 ms
Pilotes isolés, un thread chacun 0,2 ms 0,4 à 1,9 ms

Deux précautions découlent de cette convergence :

  1. Les tâches propres au hub doivent tourner sur le runtime du cœur. Aujourd'hui elles partent par tokio::spawn, donc sur le runtime de l'appelant. Le pilote des aides (moli-helpers/src/lib.rs:605-632) démarre ainsi les horloges globales des calculs (computed_clock.rs:16), des dépendances (dependency_hub.rs:456) et des durées (duration_hub.rs:279). Avec un thread par pilote, ces horloges vivraient sur le thread du pilote des aides : s'il bloque, tous les calculs de la maison s'arrêtent. Le hub doit recevoir à sa construction le Handle du runtime du cœur et y lancer ses tâches.
  2. Le hub doit se protéger des inondations. Un pilote isolé qui publie 100 000 valeurs par seconde ne bloque plus personne par son thread, mais il prend le verrou du modèle et remplit le bus. Il faut un budget d'événements par pilote, et une coalescence par point au-delà de ce budget (la dernière valeur gagne).

4.4 Une voie par appareil derrière un pont (C2)

Un pont, 20 lampes, une lampe muette (chaque requête vers elle attend 4 s, le délai de moli-net), 25 ordres par seconde pendant 10 s :

Stratégie Ordres aux lampes saines réussis Médiane Pire Lampe muette
Boucle unique 37 à 42 sur 237 (16 à 18 %) ~4,0 s 4,6 s 4,0 s, ou refus immédiat quand la file est pleine
Voie par appareil 237 sur 237 32 ms 33 à 37 ms 5,0 s (délai de l'ordre), file bornée
Voies + disjoncteur 237 sur 237 32 ms 33 à 52 ms refus en moins d'1 ms une fois le disjoncteur ouvert (après deux délais de 4 s), appareil hors ligne

La boucle unique est le modèle le plus courant dans le dépôt (V1, section 5.2) : une lampe muette fait échouer plus de huit ordres sur dix vers les lampes saines. Une voie par appareil (file bornée à 8, un ordre en vol, échéance revérifiée avant l'envoi) les isole complètement.

C'est le cas « une seule API » : Hue, Zigbee2MQTT, TaHoma, ou un service cloud.

Lancer une tâche par ordre sans plafond par appareil semble plus « parallèle », mais les requêtes vers la lampe muette occupent les 4 places de l'API et les lampes saines attendent 1,4 s en médiane. 6.2 Le mécanisme proposé

  1. Instantané et journal. La machine principale pousse à la machine de secours un instantané de l'état d'exécution (20 à 54 Kio compressés selon ce qu'il contient, écrit et synchronisé en 7,5 à 10 ms) toutes les quelques secondes, plus les fichiers métier à chaque écriture et le journal des changements (1,3 Mio par jour compressé, 9 octets par changement, R2). Même contrat que l'archive : HTTP borné, aucun disque partagé.
  2. Secours passif. La machine de secours tourne, à jour, mais ne se connecte à aucun appareil ni service : pas de MQTT avec le même identifiant client, pas de session Tuya locale (une seule par appareil), pas de rafraîchissement de jeton OAuth (les jetons tournants s'invalideraient entre eux), pas de connexion cloud qui ferait bannir le compte.
  3. Bascule. Un humain ou le chien de garde de l'hôte décide. La machine de secours incrémente une époque, l'écrit, active ses pilotes, reprend les baux et les exécutions, et se fait trouver sous le même nom (alias mDNS ou DNS, tunnel).
  4. Jamais deux maîtres. L'ancienne machine, si elle revient, voit une époque plus grande et reste passive. Une bascule par chien de garde doit d'abord arrêter l'ancienne (conteneur ou alimentation) avant d'activer la nouvelle.
  5. Valeurs reprises. Elles gardent leur horodatage d'origine et ne sont pas des changements : le moteur ne déclenche rien dessus (déjà le cas au démarrage). Les pilotes les confirment en quelques secondes.

8. Limites

  • Bancs synthétiques sur Apple M4 : les rapports entre options sont fiables, les durées absolues ne le sont pas pour le Pi ; aucune mesure sur de vrais appareils.
  • Les comptes des deux instances viennent d'une capture du 17 octobre 2026 ; les attributs de states.json sont expurgés (au plus 7 clés par entité), d'où l'usage des tailles du Recorder.
  • Le banc I1 compare des algorithmes, pas deux moteurs complets ; le banc W, lui, mesure le vrai moteur.
  • La bascule n'a pas été jouée de bout en bout ; seules ses briques (instantané, relecture, journal) ont été mesurées.

struct Compte;
static OCTETS: AtomicIsize = AtomicIsize::new(0);
unsafe impl GlobalAlloc for Compte {
    unsafe fn alloc(&self, l: Layout) -> *mut u8 {
        let p = unsafe { System.alloc(l) };
        if !p.is_null() {
            OCTETS.fetch_add(l.size() as isize, Ordering::Relaxed);
        }
        p
    }
    unsafe fn dealloc(&self, p: *mut u8, l: Layout) {
        unsafe { System.dealloc(p, l) };
        OCTETS.fetch_sub(l.size() as isize, Ordering::Relaxed);
    }
    unsafe fn realloc(&self, p: *mut u8, l: Layout, n: usize) -> *mut u8 {
        let q = unsafe { System.realloc(p, l, n) };
        if !q.is_null() {
            OCTETS.fetch_add(n as isize - l.size() as isize, Ordering::Relaxed);
        }
        q
    }
}

/// Compte les avertissements « automations lagged » du moteur et les événements manqués.
struct Retards {
    fois: Arc<AtomicUsize>,
    manques: Arc<AtomicU64>,
}
impl<S: tracing::Subscriber> tracing_subscriber::Layer<S> for Retards {
    fn on_event(&self, e: &tracing::Event<'_>, _: tracing_subscriber::layer::Context<'_, S>) {
        if *e.metadata().level() != tracing::Level::WARN {
            return;
        }
        struct V(bool, u64);
        impl tracing::field::Visit for V {
            fn record_debug(&mut self, f: &tracing::field::Field, v: &dyn std::fmt::Debug) {
                if f.name() == "message" && format!("{v:?}").contains("automations lagged") {
                    self.0 = true;
                }
            }
            fn record_u64(&mut self, f: &tracing::field::Field, v: u64) {
                if f.name() == "missed" {
                    self.1 = v;
                }
            }
        }
        let mut v = V(false, 0);
        e.record(&mut v);
        if v.0 {
            self.fois.fetch_add(1, Ordering::Relaxed);
            self.manques.fetch_add(v.1, Ordering::Relaxed);
        }
    }
}

const CAPTEURS: usize = 1_800; // 360 appareils × 5 valeurs
const LAMPES: usize = 400; // une lampe par automatisme
const CHAUDS: usize = 10; // capteurs partagés par 20 % des automatismes
const BRUIT: std::ops::Range<usize> = 1_000..1_700; // capteurs qui ne déclenchent rien

fn capteur(s: usize) -> (DeviceId, String) {
    (DeviceId::from(format!("maison:c{}", s / 5)), format!("v{}", s % 5))
}
fn lampe(k: usize) -> PointId {
    PointId::from(format!("maison:l{k}/on"))
}

struct Banc {
    arrivees: Mutex<Vec<(usize, Instant)>>,
}

struct Maison {
    banc: Arc<Banc>,
    injections: Mutex<Option<mpsc::UnboundedReceiver<(usize, f64)>>>,
}

impl Driver for Maison {
    fn kind(&self) -> &'static str {
        "maison"
    }
    fn run<'a>(&'a self, ctx: &'a mut DriverCtx) -> BoxFuture<'a, anyhow::Result<()>> {
        Box::pin(async move {
            let instance = ctx.instance().clone();
            let numerique = |key: String| PointSpec {
                key: key.clone().into(),
                label: key.into(),
                kind: Kind::Numeric { min: None, max: None, step: None },
                access: Access { read: true, write: false },
                unit: None,
                semantic: Semantic::Other,
            };
            for d in 0..CAPTEURS / 5 {
                let id = DeviceId::from(format!("maison:c{d}"));
                ctx.upsert_device(Device {
                    id: id.clone(),
                    instance: instance.clone(),
                    native_name: format!("capteur {d}").into(),
                    manufacturer: None,
                    model: None,
                    description: None,
                    native_room: None,
                    members: vec![],
                    points: (0..5).map(|k| numerique(format!("v{k}"))).collect(),
                });
                for k in 0..5 {
                    ctx.set_state(&id, &format!("v{k}"), Value::Float(0.0));
                }
            }
            for k in 0..LAMPES {
                let id = DeviceId::from(format!("maison:l{k}"));
                ctx.upsert_device(Device {
                    id: id.clone(),
                    instance: instance.clone(),
                    native_name: format!("lampe {k}").into(),
                    manufacturer: None,
                    model: None,
                    description: None,
                    native_room: None,
                    members: vec![],
                    points: vec![PointSpec {
                        key: "on".into(),
                        label: "on".into(),
                        kind: Kind::Binary,
                        access: Access { read: true, write: true },
                        unit: None,
                        semantic: Semantic::OnOff,
                    }],
                });
                ctx.set_state(&id, "on", Value::Bool(false));
            }
            let mut injections = self.injections.lock().unwrap().take().expect("une seule exécution");
            ctx.ready();
            loop {
                tokio::select! {
                    cmd = ctx.next_command() => {
                        let Some(cmd) = cmd else { return Ok(()) };
                        let k: usize = cmd.device.id.as_str()["maison:l".len()..].parse().unwrap();
                        self.banc.arrivees.lock().unwrap().push((k, Instant::now()));
                        ctx.set_state(&cmd.device.id, &cmd.key, cmd.value.clone());
                        cmd.reply(Ok(()));
                    }
                    inj = injections.recv() => {
                        let Some((s, v)) = inj else { return Ok(()) };
                        let (id, key) = capteur(s);
                        ctx.set_state(&id, &key, Value::Float(v));
                    }
                }
            }
        })
    }
}

struct Balayage {
    autos: Vec<Auto>,
    derniers: HashMap<String, Value>,
    etat: BTreeMap<String, Value>,
}

fn comparer(cur: &Value, op: Op, attendu: &Value) -> bool {
    match (cur.as_f64(), attendu.as_f64(), op) {
        (Some(c), Some(v), Op::Ge) => c >= v,
        (Some(c), Some(v), Op::Gt) => c > v,
        (Some(c), Some(v), Op::Eq) => (c - v).abs() < 1e-9,
        _ => false,
    }
}

impl Balayage {
    fn tient(&self, r: &Regle) -> bool {
        let point = r.point.clone(); // PointId::from(point)
        let Some(cur) = self.etat.get(&point).cloned() else { return false }; // hub.state
        let attendu = r.valeur.clone(); // canonical_expected
        comparer(&cur, r.op, &Value::from_json(&attendu)) // same / as_f64
    }
    fn evenement(&mut self, point: &str, v: Value) -> usize {
        self.etat.insert(point.to_owned(), v.clone());
        let cle = point.to_string();
        let avant = self.derniers.insert(cle.clone(), v.clone());
        if avant.as_ref() == Some(&v) {
            return 0;
        }
        let mut lances = 0;
        for a in &self.autos {
            if a.declencheur == cle && a.regles.iter().all(|r| self.tient(r)) {
                lances += 1;
            }
        }
        lances
    }
}

struct Compile {
    etat: Vec<f64>,
    par_point: Vec<Vec<u32>>,
    regles: Vec<Vec<(u32, Op, f64)>>,
}

impl Compile {
    fn depuis(autos: &[Auto], points: &HashMap<String, u32>) -> Self {
        let mut par_point = vec![Vec::new(); points.len()];
        let mut regles = Vec::with_capacity(autos.len());
        for (k, a) in autos.iter().enumerate() {
            par_point[points[&a.declencheur] as usize].push(k as u32);
            regles.push(
                a.regles
                    .iter()
                    .map(|r| (points[&r.point], r.op, Value::from_json(&r.valeur).as_f64().unwrap()))
                    .collect(),
            );
        }
        Self { etat: vec![0.0; points.len()], par_point, regles }
    }
    fn evenement(&mut self, p: u32, v: f64) -> usize {
        let avant = std::mem::replace(&mut self.etat[p as usize], v);
        if avant == v {
            return 0;
        }
        let mut lances = 0;
        for &a in &self.par_point[p as usize] {
            if self.regles[a as usize].iter().all(|&(q, op, x)| {
                let c = self.etat[q as usize];
                match op {
                    Op::Ge => c >= x,
                    Op::Gt => c > x,
                    Op::Eq => (c - x).abs() < 1e-9,
                }
            }) {
                lances += 1;
            }
        }
        lances
    }
}

fn interpreter(e: &serde_json::Value, vars: &HashMap<String, f64>) -> f64 {
    if let Some(c) = e.get("const") {
        return c.as_f64().unwrap();
    }
    if let Some(v) = e.get("var") {
        return vars[v.as_str().unwrap()];
    }
    let args: Vec<f64> = e["args"].as_array().unwrap().iter().map(|a| interpreter(a, vars)).collect();
    match e["op"].as_str().unwrap() {
        "sub" => args[0] - args[1],
        "gt" => f64::from(u8::from(args[0] > args[1])),
        "and" => f64::from(u8::from(args.iter().all(|a| *a != 0.0))),
        "or" => f64::from(u8::from(args.iter().any(|a| *a != 0.0))),
        "between" => f64::from(u8::from(args[1] <= args[0] && args[0] < args[2])),
        _ => unreachable!(),
    }
}

enum Expr {
    Const(f64),
    Var(usize),
    Sub(Box<Expr>, Box<Expr>),
    Gt(Box<Expr>, Box<Expr>),
    And(Vec<Expr>),
    Or(Vec<Expr>),
    Between(Box<Expr>, Box<Expr>, Box<Expr>),
}

fn compiler(e: &serde_json::Value, slots: &HashMap<&str, usize>) -> Expr {
    if let Some(c) = e.get("const") {
        return Expr::Const(c.as_f64().unwrap());
    }
    if let Some(v) = e.get("var") {
        return Expr::Var(slots[v.as_str().unwrap()]);
    }
    let a: Vec<Expr> = e["args"].as_array().unwrap().iter().map(|x| compiler(x, slots)).collect();
    let mut it = a.into_iter();
    match e["op"].as_str().unwrap() {
        "sub" => Expr::Sub(Box::new(it.next().unwrap()), Box::new(it.next().unwrap())),
        "gt" => Expr::Gt(Box::new(it.next().unwrap()), Box::new(it.next().unwrap())),
        "and" => Expr::And(it.collect()),
        "or" => Expr::Or(it.collect()),
        "between" => Expr::Between(Box::new(it.next().unwrap()), Box::new(it.next().unwrap()), Box::new(it.next().unwrap())),
        _ => unreachable!(),
    }
}

fn evaluer(e: &Expr, v: &[f64]) -> f64 {
    match e {
        Expr::Const(c) => *c,
        Expr::Var(i) => v[*i],
        Expr::Sub(a, b) => evaluer(a, v) - evaluer(b, v),
        Expr::Gt(a, b) => f64::from(u8::from(evaluer(a, v) > evaluer(b, v))),
        Expr::And(xs) => f64::from(u8::from(xs.iter().all(|x| evaluer(x, v) != 0.0))),
        Expr::Or(xs) => f64::from(u8::from(xs.iter().any(|x| evaluer(x, v) != 0.0))),
        Expr::Between(x, lo, hi) => {
            let x = evaluer(x, v);
            f64::from(u8::from(evaluer(lo, v) <= x && x < evaluer(hi, v)))
        }
    }
}

const LAMPES: usize = 20;
const MUETTE: usize = 0;

#[derive(Clone, Copy, PartialEq)]
enum Strategie {
    /// Une seule boucle attend chaque réponse (le modèle le plus courant dans le dépôt).
    BoucleUnique,
    /// Une tâche par ordre, sans plafond par appareil.
    TacheParOrdre,
    /// Une voie par appareil : file bornée, un ordre en vol, échéance revérifiée.
    Voies,
    /// Voies + disjoncteur par appareil : après 2 échecs, refus immédiat 30 s.
    VoiesDisjoncteur,
}

struct Pont {
    strategie: Strategie,
    /// L'API du pont n'accepte que `concurrence` requêtes à la fois.
    api: Arc<Semaphore>,
}

async fn appel(api: &Semaphore, appareil: usize) -> Result<(), String> {
    let _jeton = api.acquire().await.unwrap();
    if appareil == MUETTE {
        // Aucune réponse : le délai de 4 s par étape de moli-net finit par tomber.
        tokio::time::sleep(Duration::from_secs(4)).await;
        Err("délai dépassé".into())
    } else {
        tokio::time::sleep(Duration::from_millis(30)).await;
        Ok(())
    }
}

fn indice(cmd: &CommandRequest) -> usize {
    cmd.device.id.as_str()["pont:lampe".len()..].parse().unwrap()
}

impl Driver for Pont {
    fn kind(&self) -> &'static str {
        "pont"
    }
    fn run<'a>(&'a self, ctx: &'a mut DriverCtx) -> BoxFuture<'a, anyhow::Result<()>> {
        Box::pin(async move {
            for i in 0..LAMPES {
                let id = ctx.device_id(&format!("lampe{i}"));
                ctx.upsert_device(lampe(id.clone(), &ctx.instance().clone()));
                ctx.set_availability(&id, true);
            }
            ctx.ready();
            match self.strategie {
                Strategie::BoucleUnique => {
                    while let Some(cmd) = ctx.next_command().await {
                        let i = indice(&cmd);
                        let r = appel(&self.api, i).await;
                        cmd.reply(r);
                    }
                }
                Strategie::TacheParOrdre => {
                    let mut taches = tokio::task::JoinSet::new();
                    while let Some(cmd) = ctx.next_command().await {
                        let api = self.api.clone();
                        taches.spawn(async move {
                            let i = indice(&cmd);
                            let r = appel(&api, i).await;
                            cmd.reply(r);
                        });
                        while taches.try_join_next().is_some() {}
                    }
                }
                Strategie::Voies | Strategie::VoiesDisjoncteur => {
                    let disjoncteur = self.strategie == Strategie::VoiesDisjoncteur;
                    let mut voies = Vec::new();
                    let mut taches = tokio::task::JoinSet::new();
                    let hors_ligne = Arc::new(Mutex::new(Vec::<usize>::new()));
                    for i in 0..LAMPES {
                        let (tx, mut rx) = mpsc::channel::<CommandRequest>(8);
                        voies.push(tx);
                        let api = self.api.clone();
                        let hors_ligne = hors_ligne.clone();
                        taches.spawn(async move {
                            let (mut echecs, mut ouvert_jusqua) = (0u32, None::<Instant>);
                            while let Some(cmd) = rx.recv().await {
                                if cmd.abandoned() {
                                    cmd.reply(Err("expiré avant l'envoi".into()));
                                    continue;
                                }
                                if let Some(t) = ouvert_jusqua {
                                    if Instant::now() < t {
                                        cmd.reply(Err("injoignable : disjoncteur ouvert".into()));
                                        continue;
                                    }
                                    ouvert_jusqua = None; // essai à demi-ouvert
                                }
                                let r = appel(&api, i).await;
                                if r.is_err() {
                                    echecs += 1;
                                    if disjoncteur && echecs >= 2 {
                                        ouvert_jusqua = Some(Instant::now() + Duration::from_secs(30));
                                        hors_ligne.lock().unwrap().push(i);
                                        // Les ordres déjà en file n'attendent pas : refus immédiat.
                                        while let Ok(c) = rx.try_recv() {
                                            c.reply(Err("injoignable : disjoncteur ouvert".into()));
                                        }
                                    }
                                } else {
                                    echecs = 0;
                                }
                                cmd.reply(r);
                            }
                        });
                    }
                    loop {
                        tokio::select! {
                            cmd = ctx.next_command() => {
                                let Some(cmd) = cmd else { break };
                                let i = indice(&cmd);
                                if let Err(e) = voies[i].try_send(cmd) {
                                    let cmd = match e {
                                        mpsc::error::TrySendError::Full(c) | mpsc::error::TrySendError::Closed(c) => c,
                                    };
                                    cmd.reply(Err("file de l'appareil pleine".into()));
                                }
                                let tombes: Vec<usize> = std::mem::take(&mut *hors_ligne.lock().unwrap());
                                for t in tombes {
                                    ctx.set_availability(&ctx.device_id(&format!("lampe{t}")), false);
                                }
                            }
                            fin = taches.join_next() => {
                                // Une voie qui meurt fait relancer tout le pilote : jamais en silence.
                                anyhow::bail!("voie arrêtée : {fin:?}");
                            }
                        }
                    }
                }
            }
            Ok(())
        })
    }
}

//! octet avec un allocateur qui compte, sur la forme réelle de deux Home Assistant

use std::alloc::{GlobalAlloc, Layout, System};

struct Compte;
static OCTETS: AtomicIsize = AtomicIsize::new(0);
static BLOCS: AtomicIsize = AtomicIsize::new(0);

unsafe impl GlobalAlloc for Compte {
    unsafe fn alloc(&self, l: Layout) -> *mut u8 {
        let p = unsafe { System.alloc(l) };
        if !p.is_null() {
            OCTETS.fetch_add(l.size() as isize, Ordering::Relaxed);
            BLOCS.fetch_add(1, Ordering::Relaxed);
        }
        p
    }
    unsafe fn dealloc(&self, p: *mut u8, l: Layout) {
        unsafe { System.dealloc(p, l) };
        OCTETS.fetch_sub(l.size() as isize, Ordering::Relaxed);
        BLOCS.fetch_sub(1, Ordering::Relaxed);
    }
    unsafe fn realloc(&self, p: *mut u8, l: Layout, n: usize) -> *mut u8 {
        let q = unsafe { System.realloc(p, l, n) };
        if !q.is_null() {
            OCTETS.fetch_add(n as isize - l.size() as isize, Ordering::Relaxed);
        }
        q
    }
}

#[global_allocator]
static A: Compte = Compte;

fn tas() -> (isize, isize) {

/// Forme réunie des deux instances : 496 appareils, 2 264 valeurs vivantes, dont

const VINGTILES: [f64; 20] = [

fn fenetres(jours: f64) {
    let total: f64 = (0..SERIES).map(|s| taux(s) * jours).sum();
    // a) naïf : (horodatage, Value) dans une VecDeque par série.
    let avant = tas();
    let mut naif: HashMap<u32, VecDeque<(u64, Value)>> = HashMap::new();
    for s in 0..SERIES {
        let n = (taux(s) * jours).round() as usize;
        let q = naif.entry(s as u32).or_default();
        for i in 0..n {
            q.push_back((1_792_000_000_000 + i as u64 * 1000, Value::Float(i as f64)));
        }
    }
    let c_naif = cout(avant, tas());
    // b) compact : décalage en secondes (u32) + valeur f32, colonnes par série.
    let avant = tas();
    let mut compact: HashMap<u32, (Vec<u32>, Vec<f32>)> = HashMap::new();
    for s in 0..SERIES {
        let n = (taux(s) * jours).round() as usize;
        let (t, v) = compact.entry(s as u32).or_default();
        t.reserve_exact(n);
        v.reserve_exact(n);
        for i in 0..n {
            t.push(i as u32);
            v.push(i as f32);
        }
    }
    let c_compact = cout(avant, tas());
    // c) mixte : brut compact sous 1 changement/min, seaux par minute au-delà.
    let avant = tas();
    let mut mixte: HashMap<u32, (Vec<u32>, Vec<f32>)> = HashMap::new();
    let mut seaux: HashMap<u32, Vec<[f32; 5]>> = HashMap::new();
    for s in 0..SERIES {
        let n = (taux(s) * jours).round() as usize;
        if taux(s) <= 1_440.0 {
            let (t, v) = mixte.entry(s as u32).or_default();
            t.reserve_exact(n);
            v.reserve_exact(n);
            for i in 0..n {
                t.push(i as u32);
                v.push(i as f32);
            }
        } else {
            let minutes = (1_440.0 * jours) as usize;
            let b = seaux.entry(s as u32).or_default();
            b.reserve_exact(minutes);
            for m in 0..minutes {
                b.push([m as f32, 0.0, 1.0, 0.5, 3.0]);
            }
        }
    }
    let c_mixte = cout(avant, tas());
    println!(
        "- fenêtre {jours} j : {:.0} relevés → naïf {} ; compact {} ; mixte (seaux/minute pour les séries > 1/min) {}",
        total,
        mio(c_naif),
        mio(c_compact),
        mio(c_mixte)
    );
    drop((naif, compact, mixte, seaux));
}
